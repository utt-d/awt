# AWT 0.8.0 改修後監査

- 対象: AWT 0.8.0 / versionCode 9
- 監査日: 2026-07-26
- 実動作環境: Android 16 / API 36、1080×2400

## 1. 改修結果

通常のアラビア数字、背景色、Aurora、水面の光、円周残像、時間表示サイズ、
タイマー設定の開閉、操作位置を0.8.0として再設計した。

### 数字

- 0～9を曲線主体の三次ベジェ字形へ変更
- 各ベジェ区間を12点へ標本化
- 弧長に沿って共通の56点へ再サンプリング
- 56対応点の補間による一つのパスとしての数字モーフ
- 0、2、4、8を含む`04:28`を82spのアラーム編集画面で目視確認
- 0～9全字形が正規化領域内にあり、実際の曲率を含むことを単体テストで確認

### 背景

- テーマとは独立した7背景色を追加
- 紫紺の選択と、APK再インストール後の保持を確認
- Auroraを12秒循環の複数光場と三本の曲線光帯へ変更
- 3秒差の画像で光帯位置、曲率、明度分布の変化を確認
- 水面の光を、比率・重み・方向の異なる6波、局所集光、付着から残留へ遷移する白波で再構成
- 全幅輪郭は曲率を増やして低不透明度化し、横線ではなく局所集光と白波を主役に調整

### 円周

- 半径の脈動と縮小を廃止
- 点状ヘッド、粒子、ダスト、橙色の副軌道を廃止
- Primary色だけの連続Sweep Gradientへ変更
- 固定半径を1秒で時計回りに1周
- 先端を広い色勾配で減衰させ、点ではなく残像として表示
- 3秒の画面録画を2fpsで抽出し、半径が固定されたまま一周／秒で進むことを確認

### 表示と操作

- デジタル時計94sp
- アラーム入力82sp
- タイマー設定48sp、動作中58sp
- ストップウォッチ68sp
- 外観操作を右上端の低強調アイコンだけに変更
- タイマーは数字だけを初期表示し、時間領域タップ後にテンキー、プリセット、開始操作を展開
- ストップウォッチの時間、リセット、開始を画面下半分へ配置
- アラームのテンキー、キャンセル、保存を下側へ配置し、固定保存バーを維持
