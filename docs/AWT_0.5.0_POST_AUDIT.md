# AWT 0.5.0 改修後監査

- 対象: AWT 0.5.0 / versionCode 5
- 比較対象: AWT 0.4.0
- 監査日: 2026-07-23
- 実機環境: Android 16 / API 36 エミュレータ、1080×2400、420dpi

## 1. 結果

今回の3要望はすべて実装し、API 36上で表示と操作を確認した。

| 要望 | 実装 | 実動作確認 |
|---|---|---|
| 上端への偏りとカメラ衝突 | `safeDrawing`上端を本文に適用 | 見出し・時計・テンキーが安全領域より下に表示 |
| 届きにくい操作 | アラーム保存／キャンセルを下端固定 | スクロール位置にかかわらず常時表示 |
| 時刻の無効数字 | 桁位置と入力済み接頭辞から有効性を計算 | `23`入力後に6〜9がグレー化し、タップ不可 |
| タイマーの無効数字 | 分・秒の十の位を0〜5に限定 | `99`入力後に6〜9がグレー化し、タップ不可 |
| 数字のモーフィング | 上下移動、フェード、拡縮を合成 | 時計・入力・カウントの変更桁へ適用 |
| 時計回りの波 | 内外二重軌道、光点、10段の残響弧 | 0.8秒差の画像で時計回りの移動を確認 |

## 2. 縦配置の再検討

最初の実装ではストップウォッチを0.4.0より50dp下げたが、API 36の縦長画面では開始ボタンがまだ上側にあり、
下半分の空白を活用できていなかった。このため追加で104dp下げ、合計154dp下方へ移した。

最終状態では、経過時間を画面上端から約3分の1、開始／停止操作を画面中央付近に置き、
計測モード切替と主要ナビゲーションは画面下部に維持した。ラップ一覧は残り高さを使う可変領域である。

アラーム一覧は一覧としての走査性を保つためカードを上から並べるが、追加操作は右下に固定する。
時計は中央配置、タイマーは設定テンキーと開始操作が中段から下段に連続する配置とした。

## 3. 入力制約

### アラーム

- 先頭: 0〜2
- 先頭が2の場合の2桁目: 0〜3
- 分の十の位: 0〜5
- それ以外: 0〜9

### タイマー

- 時: 00〜99
- 分・秒の十の位: 0〜5
- 分・秒の一の位: 0〜9

無効キーは背景不透明度32%、文字不透明度30%とし、クリック自体を無効にした。
パーサーによる最終範囲検証も残している。

## 4. 視覚効果

- 桁入力: 新しい桁を72%から拡大し、古い桁を118%へ拡大しながら交代。
- 時計／カウント: 新しい桁を74%から拡大し、古い桁を116%へ拡大しながら交代。
- 外周波: Primary色とSecondary色を180度ずらし、1周6.4秒で時計回りに移動。
- 波形: 円周上の半径を小さく揺らす短い弧と先頭光点で、進行方向と残響を示す。

## 5. 電池とアクセシビリティ

- 外周波は対象画面が前面、省電力OFF、「動きを減らす」OFFの場合だけ動作。
- それ以外は無限アニメーションを生成せず静止描画。
- 省電力または「動きを減らす」時は時計・タイマー更新を1Hzへ低下。
- 同条件のストップウォッチ描画は4Hzへ低下し、経過計算は単調時計で保持。
- 画面離脱またはバックグラウンド移行で画面固有ループを停止。
- フォント1.3倍で、見出し、テンキー、曜日、詳細設定、下部キャンセル／保存が操作可能。
