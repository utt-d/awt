# AWT 0.11.0 改修後監査

- 対象: AWT 0.11.0 / versionCode 12
- 監査日: 2026-07-26
- 実動作環境: Android 16 / API 36、1080×2400、420dpi

## 1. 結果

0.10.0で残っていた標準数字モーフの輪郭崩れ、秒表示の色、数字の縦横比、
タイマー一時停止時の位置移動、画面間で共有されていた外観設定を修正した。

## 2. 標準数字モーフ

- Android標準`sans-serif`の0～9輪郭を取得し、外側輪郭と内側カウンターを分離する。
- 各輪郭を84点へ再標本化し、開始点は最短距離、方向は符号付き面積を使って対応させる。
- 複数カウンターは中心位置が近いもの同士を対応させ、6・8・9の穴が交差しないようにする。
- モーフの開始・終了付近ではAndroid標準フォントの実輪郭へ滑らかに重ね、安定時の字形を保証する。
- 実画面で`36:48:39`を表示し、3・4・6・8・9の輪郭、8の2つの穴、6・9の穴を確認した。
- 標準フォントから得た実アスペクト比を保持し、従来の過度な縦長表示を解消した。

## 3. 時計の秒表示

- デジタル時計と秒円弧内の秒表示を、アクセント色ではなく画面固有の文字色へ連動させた。
- 時計の文字色をシアンへ変更し、時・分と秒が同色になることを確認した。
- 同時にアラームと計測は既定の白色を保持し、設定が他画面へ波及しないことを確認した。

## 4. タイマー配置

- 動作中と一時停止中の上余白を同一の132dpへ統一した。
- 5分タイマーを開始して一時停止し、円と時刻表示の中心位置が変わらないことを確認した。
- 一時停止中も停止・再開操作を時刻表示内へ維持する。

## 5. 画面別外観設定

- `AppearanceScreen`をアラーム・時計・計測の3種類として定義した。
- テーマ、背景色、文字色、背景モーション、数字、動きを減らす設定を画面ごとに保存する。
- 時計固有の時計盤と円周表示は時計の設定画面だけに表示する。
- 0.10.0以前の共通設定は初回起動時に3画面へ複製し、その後は独立して更新する。
- 各画面の左下アイコンから「アラームの外観」「時計の外観」「計測の外観」を開ける。

## 7. 注意

- 数字モーフの中間形状は輪郭補間であり、フォントのバリアブル軸ではない。
- OpenGL背景の性能は端末GPUに依存するため、重要端末では省電力と発熱を個別確認する。
- GitHub ReleaseのAPKはAWT専用の本番証明書で署名したReleaseビルドである。
- 以前のデバッグ署名版から初めて移行するときは、署名が異なるためアンインストールが必要である。
