# AWT プロダクト／UI仕様書

- 文書版: 2.0
- 対象アプリ版: 0.11.0
- 更新日: 2026-07-26
- 対象OS: Android 8.0（API 26）以上

## 1. 目的

AWTは、目覚まし、卓上時計、タイマー、ストップウォッチを一つにまとめたAndroid向け時計アプリである。
標準時計よりも、時刻を設定する行為そのものが速く、気持ちよく、毎日眺めたくなることを目指す。

一方で、特定の既存製品の名称、ロゴ、画像、音源、画面構成、アニメーションを複製しない。
AWT独自の「Aurora」表現、情報構造、コンポーネントを用いる。

## 2. 設計原則

### 2.1 迷わせない

- 主要ナビゲーションは「アラーム」「時計」「計測」の3項目とする。
- アラーム追加は、アラーム一覧で常に見える「追加」ボタンから開始する。
- 保存、スヌーズ、停止など結果の大きい操作は、文字ラベルを常時表示する。
- ジェスチャーは近道として提供し、ジェスチャーだけを必須にしない。
- 高度な設定は折りたたみ、初期画面では時刻、繰り返し、ラベルに集中させる。

### 2.2 見飽きない

- 背景には静的な単色ではなく、AWT独自の非対称なAurora光彩を使用する。
- 通常画面の装飾は控えめにし、時刻編集と時計画面に視覚的な動きを集中させる。
- テーマと時計盤の拡張を前提に、色と時計表示を分離した構造にする。

### 2.3 美しく、読みやすい

- 大きな時刻、広い余白、少数のアクセント色で階層を作る。
- 本文、時刻、操作ボタンは暗い背景に対して十分なコントラストを確保する。
- 通常画面は状態バーを隠し、画面内の情報へ視線を集中させる。
- 日本語ロケールでは日付と曜日を日本語で統一する。

### 2.4 親しみを残しつつ独立する

時計アプリに求められる「一目で時刻が分かる」「素早くアラームを作れる」「穏やかに起きられる」
という体験価値は維持する。一方、円形バブルや既存製品固有の素材・音・画面遷移は使用せず、
画面内数字入力、広い余白、Aurora表現をAWTの中心的な操作・視覚言語とする。

### 2.5 電池を浪費しない

- 現在時刻の更新は時計画面が表示されている間だけ行う。
- ストップウォッチの描画更新は画面が前面にある間だけ行う。
- Auroraアニメーションは前景画面だけで動作し、省電力時は静止できる設計とする。
- アラーム待機中に常駐ループ、定期通信、不要なWakeLockを使用しない。
- 正確なアラームはAndroidのAlarmManagerに委譲する。

## 3. 情報構造

### 3.1 下部ナビゲーション

| 項目 | 主目的 | 初期表示 |
|---|---|---|
| アラーム | アラームの一覧、追加、編集、有効化 | アラーム一覧 |
| 時計 | 現在時刻を美しく大きく表示 | デジタル時計 |
| 計測 | タイマーとストップウォッチ | タイマー |

3画面は下部項目のタップに加え、画面本体の左右スワイプでも切り替える。
「計測」内は下部ナビゲーション直上のセグメントで「タイマー」「ストップウォッチ」を切り替える。
全画面表示中も本文はディスプレイカットアウトの安全領域より下に配置し、主要操作は画面下側へ置く。

## 4. 画面仕様

### 4.1 共通背景

- 上部を深い青、下部を夜色にした縦グラデーションを基礎にする。
- 左上と右下に、透明度の低い非対称なAurora光彩を置く。
- Auroraはアプリが前面にあり、「動きを減らす」と省電力モードがともにOFFの場合だけ動かす。
- OLEDテーマでは光彩を描画せず、背景を純黒にする。
- 文字色は原則 `TextPrimary`、補助情報は `TextMuted` を用いる。

### 4.2 アラーム一覧

- 上部には画面名だけを表示し、現在時刻とアプリ名は表示しない。
- 各カードは設定時刻、ラベル、繰り返し、次回曜日、ON/OFFを表示する。
- カード本体のタップで編集する。
- 削除アイコンを押した場合は、アラーム名と時刻を示す確認ダイアログを出す。
- 空状態には「最初のアラームを追加しましょう」と追加導線を表示する。

### 4.3 アラーム編集

ダイアログではなく全画面で表示する。

#### 見出しと固定操作バー

- 上部: 非操作の「アラームを追加」または「アラームを編集」見出し。
- 下部左: 「キャンセル」。
- 下部右: 「保存」。スクロール位置にかかわらず常に操作できる。
- 下部操作バーはナビゲーションバーの安全領域を含み、片手で届く高さに固定する。

#### 4桁時刻入力

- 時刻は`HHMM`の4桁で入力し、`HH:MM`として大きく表示する。
- 設定時刻は82spを基準とし、テンキーより強い視覚階層を与える。
- OSキーボードと時・分テキストボックスは使用せず、画面内テンキーで入力する。
- 最初の数字入力で既存時刻を置き換える。
- 1文字削除と全消去を提供する。
- 次の桁に入力すると有効時刻を作れない数字はグレーアウトし、タップできない。
- 時の先頭は0〜2、先頭が2なら次は0〜3、分の十の位は0〜5だけを有効にする。
- 防御的検証として、`00:00`から`23:59`以外では保存を無効にする。
- ドラッグによる時刻設定とTime Ribbonは使用しない。

#### 基本設定

- 曜日チップは7個が横幅に収まる等分配置とし、末尾を切らない。
- ラベルは30文字まで。

#### 詳細設定

- 初期状態では折りたたむ。
- 「徐々に音量を上げる」「バイブレーション」を含む。

### 4.4 時計

- 現在時刻を画面中央に大きく表示する。
- 秒表示と日付を表示する。
- 次の有効なアラームがある場合、その時刻とラベルを表示する。
- デジタル、秒アーク、ミニマルアナログ、24時間の4時計盤から選択できる。
- 時計画面右上端の低強調なパレットアイコンから外観を変更する。常時ラベルは表示しない。
- 外観ではテーマとは独立して、テーマ連動、深夜、深海、紫紺、森林、墨色、黒の背景色を選べる。
- 外観設定は端末内に保存し、再起動後と鳴動画面でもテーマを維持する。
- デジタル時計の時分は94spを基準とし、画面幅へ収まる範囲で最大化する。
- 通常のアラビア数字は、0～9を曲線主体の三次ベジェ字形として定義し、同じ56点へ再サンプリングして連続変形させる。
- デジタル表示は変更桁をクロスフェードせず、一つの曲線パスとしてモーフさせる。
- 時計とストップウォッチは増加方向、タイマーは減少方向へ桁を送る。
- 時刻の外周は固定半径とし、脈動、縮小、点状ヘッド、橙色の副軌道を使用しない。
- 外周にはPrimary色だけの連続Sweep Gradientを表示し、1秒で時計回りに1周させる。
- 光跡の先端と末尾は広い色勾配で消し、点ではなく残像として見せる。
- アナログ針と円弧は小数秒で滑らかに進める。
- Auroraは12秒周期の閉じた軌道を持つ光場と三本の曲線光帯で構成し、端で反転せず循環する。
- 「水面の光」は6方向の複合波、干渉から得る局所集光、波頭へ付着して残留する白波で構成する。

### 4.5 計測

#### タイマー

- 時、分、秒は`HHMMSS`の6桁画面内テンキーで入力する。
- 通常時は320dpの円内に48spの時間だけを主表示し、テンキー、プリセット、開始操作は隠す。
- 時間表示をタップすると設定操作を展開する。
- 動作中の残り時間は58spを基準とする。
- OSキーボードと時・分・秒テキストボックスは使用しない。
- 分と秒は`00`から`59`、時は`00`から`99`を有効範囲とする。
- 分・秒の十の位では6〜9をグレーアウトし、タップできない。
- 5分、10分、20分、30分のプリセットを提供する。
- 動作中は残り時間を桁単位のアニメーションで表示する。
- 設定時間／残り時間の外周にも時計回りの波を表示する。
- 動作中に `＋1分`、`＋5分` で延長できる構造を目標とする。

#### ストップウォッチ

- 経過時間は暗い背景でも常に高コントラストで表示する。
- スタート／停止、ラップ、再開、リセットを文字付きボタンで提供する。
- バックグラウンドでは描画更新を止め、復帰時に単調時計から経過時間を再計算する。
- ラップ番号とラップ時間は同じ補助文字色で表示する。
- 秒までは桁アニメーション、百分の一秒は軽量な等幅表示とする。
- 秒までの主表示は68spを基準とし、開始／停止操作を画面中央より下へ置く。

### 4.6 鳴動画面

- 現在時刻やアプリ名を表示せず、中央付近にラベルを表示する。
- 主要操作は中央の大きな「10分スヌーズ」とする。
- 「停止」は常に見える独立ボタンとし、スヌーズと誤認しない配色・形にする。
- 音量キーと端末を伏せる操作は、スヌーズの近道として維持する。
- ジェスチャーを知らなくても画面上のボタンだけで完結できる。

## 5. 視覚仕様

### 5.1 基本色

| 名称 | 値 | 用途 |
|---|---|---|
| Night | `#101521` | 背景 |
| Night Soft | `#192333` | カード |
| Mist | `#BFE9DF` | 主操作、Aurora |
| Sunrise | `#F5C978` | 時刻ハンドル、注意 |
| Coral | `#FF8F7A` | 停止、エラー |
| Text Primary | `#F4F7F9` | 主文字 |
| Text Muted | `#AEB9C6` | 補助文字 |

この基本色をDawnテーマとし、Lagoon、Ember、Aurora、Violet Night、Forest、Moon、OLEDを加えた
8テーマを提供する。各テーマは背景、カード、主操作、補助アクセント、警告色を一体で変更する。

### 5.2 文字

- 現在時刻・設定時刻: Lightウェイトを基本とする。
- 変化する数字は等幅で描画し、変更桁だけをアニメーションさせる。
- 操作ラベル: MediumまたはBold。
- 文字サイズを拡大しても保存や曜日選択が画面外へ失われない。

### 5.3 タッチ領域

- 主要操作は48dp以上。
- 小さな曜日チップも親コンテナを等分し、実質タッチ領域を確保する。
- 画面上端のカットアウト近傍には主要操作を置かない。
- 保存、計測モード切替、開始・停止などの主要操作は親指到達域を優先する。

## 6. アクセシビリティ

- 文字と背景はWCAG AA相当のコントラストを目標とする。
- アイコンだけの操作にはcontentDescriptionを付与する。
- 大きい文字設定で主要操作が切れないことを確認する。
- 「動きを減らす」でAuroraと桁アニメーションを停止できる。
- 「動きを減らす」で時計回りの波を静止できる。

## 7. 電池・性能の受け入れ条件

- アラーム待機中にアプリ独自の周期処理を行わない。
- 時計の高頻度更新は時計画面が選択されている間だけ。
- ストップウォッチの高頻度更新はLifecycleがRESUMEDのときだけ。
- 時計・計測画面離脱後、各画面固有の描画ループが停止する。
- 外周波アニメーションは対象画面が前面のときだけ動き、省電力モード中は静止する。
- 省電力時は時計とタイマーの表示更新を1Hz、ストップウォッチを4Hzへ抑える。
- ネットワーク通信を使用しない。

## 8. 機能受け入れ条件

- 初見ユーザーが15秒以内に新しいアラームを保存できる。
- アラーム編集画面で戻る・保存が常時見える。
- カメラ穴やディスプレイカットアウトと本文・操作が重ならない。
- 4桁入力で有効なアラーム時刻が保存され、無効な時刻は保存できない。
- 有効範囲外につながる数字キーはグレーアウトし、タップしても入力されない。
- 6桁入力で有効なタイマー時間を開始できる。
- 曜日チップ7個が幅360dpの端末で切れない。
- 削除は確認後にだけ実行される。
- アラーム、時計、計測の移動先をラベルだけで予測できる。
- アラーム、時計、計測を下部タップと左右スワイプの両方で移動できる。
- 鳴動画面でスヌーズと停止を一目で区別できる。
- タイマーとストップウォッチの数字が暗い背景で明瞭に読める。

- 標準数字をAndroid標準のsans-serif数字輪郭から生成し、`4`を含む0～9を一般的な数字フォントに近づける
- 各数字の外周と内側カウンターを同じ点数へ再標本化し、穴を保ったまま輪郭全体を連続モーフ
- 背景色と文字色を、色相帯と彩度・明度の2次元カラーパレットから直接選択
- 時計周囲の1秒円形アニメーションを外観設定で表示／非表示にし、設定を端末内へ保存
- タイマーの開始、一時停止、再開、停止を大きな時間表示上へ常時配置
- 一時停止した残り時間を端末内へ保存し、再開時に正確なシステムタイマーを再登録
- ストップウォッチも同じ円形オーバーレイ操作へ統一
- 水面の活動白波を局所的な複合波頂・曲率へ結び付け、直線状の白水帯を廃止
- 同じ泡沫信号を現在・直近・過去の時間から参照し、白波から残留泡まで連続的に低輝度化
- 水面の解析的な勾配・曲率計算を維持しつつ、320px幅・約24fpsでジャギーと負荷を調整
