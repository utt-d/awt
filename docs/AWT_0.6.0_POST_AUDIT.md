# AWT 0.6.0 改修後監査

- 対象: AWT 0.6.0 / versionCode 6
- 比較対象: AWT 0.5.0
- 監査日: 2026-07-23
- 実動作環境: Android 16 / API 36、1080×2400、420dpi

## 1. 結果

時間表示の視覚階層、操作位置、桁モーション、外周波を更新した。
他社アプリの素材やコードを使用せず、AWTのテーマ色とCompose Canvasで独立実装している。

| 項目 | 0.5.0 | 0.6.0 |
|---|---:|---:|
| アラーム設定時刻 | 52sp | 64sp |
| タイマー設定時間 | 31sp | 34sp |
| タイマー残り時間 | 38sp | 42sp |
| アラーム案内後の余白 | 12dp | 28dp |
| タイマー上端余白 | 36dp | 44dp |
| タイマー表示後の余白 | 28dp | 設定中40dp／動作中88dp |
| 外周波 | 短い弧10個 | 連続Sweep Gradient＋粒子 |

## 2. 桁モーション

単純な上下移動、フェード、線形拡縮を次の合成表現へ置き換えた。

- Springによる55%から100%への弾性進入
- 約75%桁高の移動
- 古い桁の134%拡大と反対方向への退出
- 新旧桁の短い重なりによる残像
- テーマ色の低不透明度グロー
- 変更桁だけに560ms表示する二重リング
- 桁の外縁から回転・拡散する4個の粒子

時計とストップウォッチは増加方向、タイマーは減少方向へ送る。
`9→0`の繰り上がりも時計では増加方向となる。

初期実装ではバーストが`0`の内側に見える瞬間があったため、
リング開始半径を字形外縁へ移し、中央の塗りつぶし光を撤去した。

## 3. 外周コメット波

当初は28〜36個の短い弧を重ねる方式も実装・計測したが、尾の粒状感と描画負荷が残った。
最終版では次の構成へ変更した。

- 92度の連続Sweep Gradient
- 10dpの低不透明度グロー
- 3.7dpの高輝度コア
- 白い中心を持つ波頭と9dpのヘッドグロー
- 波頭より前方の3粒子
- 尾の周囲に残る5個の微小ダスト
- Primary／Secondary色を180度ずらした内外二重軌道

これにより、離散した点線ではなく連続的に減衰する光跡となった。

## 4. フレーム計測

API 36エミュレータの`dumpsys gfxinfo`で8〜10秒間計測した。

| 構成 | Janky frames | 50th | 90th | 99th |
|---|---:|---:|---:|---:|
| 多数の短い弧 | 1.24% | 27ms | 38ms | 53ms |
| Sweep Gradient・24時間盤 | 0.41% | 27ms | 32ms | 38ms |
| Sweep Gradient・デジタル盤 | 0.33% | 24ms | 29ms | 34ms |

エミュレータ値であり実機のGPU性能を保証するものではないが、
シェーダー化によりJankと上位パーセンタイルが改善した。

## 5. レイアウト確認

- 通常フォントでアラーム時刻64spと下げたテンキーを確認。
- フォント1.3倍でも`HH:MM`が横幅に収まることを確認。
- タイマー1.3倍でも`HH:MM:SS`、テンキー、プリセット、開始、モード切替が欠けない。
- 動作中タイマーの延長／キャンセルは画面中央より下へ移動。
- 下部の保存、計測モード切替、主要ナビゲーションは固定を維持。
