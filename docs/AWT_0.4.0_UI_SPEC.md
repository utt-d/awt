# AWT 0.4.0 操作・表示仕様

- 対象: AWT 0.4.0
- 更新日: 2026-07-23
- 目的: 片手操作、入力の明瞭さ、画面の静けさ、時間表示の質を改善する

## 1. 主要画面の移動

- 主要画面は「アラーム」「時計」「計測」の3画面とする。
- 画面下部のナビゲーションをタップして移動できる。
- 画面本体を左右にスワイプしても隣の画面へ移動できる。
- スワイプ後は下部ナビゲーションの選択状態を追従させる。
- アラーム編集画面では誤操作を避けるため、主要画面スワイプを行わない。

## 2. アプリ名と現在時刻

- アプリ本体の画面内に装飾目的のアプリ名を表示しない。
- ランチャー、通知、権限設定など、OSがアプリを識別する場所では名称を維持する。
- 現在時刻は時計画面にだけ表示する。
- アラーム一覧ではアラームの設定時刻、タイマーでは残り時間、ストップウォッチでは経過時間を表示できる。

## 3. アラーム時刻入力

- Time Ribbonとドラッグによる時刻設定を廃止する。
- `HHMM`の4桁入力とする。
- OSキーボードやテキストボックスは使用せず、画面内テンキーで入力する。
- 入力中は`12:34`のように時と分を視覚的に分離する。
- 最初の数字入力で既存値を置き換え、4桁入力後に続けて数字を押した場合は新規入力を開始する。
- 1文字削除と全消去を用意する。
- `00:00`から`23:59`以外はエラー表示し、保存を無効にする。
- ラベル、繰り返し、徐々に音量を上げる、バイブレーションは従来どおり設定できる。

## 4. タイマー時間入力

- 時、分、秒のテキストボックスを廃止する。
- `HHMMSS`の6桁入力とする。
- 画面内テンキーで入力し、`00:10:00`のように表示する。
- 分と秒は`00`から`59`、時は`00`から`99`を有効範囲とする。
- 1文字削除、全消去、5分・10分・20分・30分のプリセットを用意する。
- 0秒および範囲外の値では開始できない。

## 5. タイマー／ストップウォッチ切替

- 切替操作を画面上部から撤去する。
- 親指が届きやすい、下部ナビゲーション直上に2択の切替を固定する。
- 計測内容が縦スクロールしても切替位置は移動させない。

## 6. 数字の動き

- デジタル時計、秒アーク、24時間時計、タイマー、ストップウォッチの数字は、変更桁だけが短く上下に移動しながらフェードする。
- 数字の幅が変化して表示が揺れないよう、等幅数字で描画する。
- アナログ時計と円弧は秒を小数で計算し、段階的なジャンプを抑える。
- 時計画面の更新は画面表示中に限定する。
- 「動きを減らす」が有効な場合は桁アニメーションを停止し、即時更新する。

## 7. 配色

- ストップウォッチのラップ番号とラップ時間は同じ補助文字色を使用する。
- 数字入力の未入力桁、区切り記号、エラー、確定可能状態を色だけでなく文字でも区別する。

## 8. 受け入れ条件

1. 3主要画面をタップと横スワイプの両方で移動できる。
2. 時計画面以外に共通の現在時刻ヘッダーが表示されない。
3. アプリ内に装飾的なアプリ名表示がない。
4. アラームを4桁テンキーで入力し、保存・再編集できる。
5. 無効時刻を保存できない。
6. タイマーを6桁テンキーで入力し、実際に発火できる。
7. タイマー／ストップウォッチ切替が画面下部にある。
8. ラップ番号と時間が同色である。
9. 数字変更時に桁単位のアニメーションが見える。
10. 「動きを減らす」で桁アニメーションが無効になる。
