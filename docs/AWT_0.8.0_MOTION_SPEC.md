# AWT 0.8.0 数字・背景・円周モーション仕様

- 対象: AWT 0.8.0 / versionCode 9
- 作成日: 2026-07-26
- 前提: 他社アプリの素材、コード、画面、字形データを使用しない独立実装

## 1. 目的

時刻を画面の主役として最大化し、視認性を損なう脈動や点状エフェクトを除く。
数字、背景、円周の動きは装飾量ではなく、連続した曲線、意味のある速度、
自然な残像によって品質を高める。

## 2. 通常のアラビア数字

- 0～9をAWT独自の人文的なモノライン字形として定義する。
- 字形は三次ベジェ曲線の列で構成し、直線だけのポリラインを使用しない。
- 楕円形の0、柔らかい肩を持つ2／3／5、連続したループを持つ6／8／9とする。
- 4の骨格など可読性に必要な角は残すが、斜線と接合部には緩い曲率を与える。
- 各ベジェ区間を12点へ標本化し、弧長に沿って共通の56点へ再サンプリングする。
- 対応点を補間し、一つのパスが次の数字へ変形する。画像交換や新旧字形の重ね合わせを主表現にしない。
- 増加表示は上方向、カウントダウンは下方向の小さな慣性を付ける。
- 省電力または「動きを減らす」時は中間補間を停止し、完成字形だけを表示する。

## 3. 円周の色残像

- 円の半径は固定し、脈動、縮小、拡大を行わない。
- 点状ヘッド、先行粒子、ダスト、橙色の副軌道を使用しない。
- Primary色のSweep Gradientだけで残像を描く。
- 1秒で時計回りに1周する。
- 太い低不透明度グローと細いコアを同じ勾配で重ねる。
- 先端と末尾を十分な角度で連続減衰させ、小さな点や切断線に見せない。
- タイマーでは別の細い進捗円を残し、残像と残量情報を混同しない。

## 4. Aurora

- 12秒で閉じる循環軌道を使用し、端で折り返さない。
- 複数のRadialGradient光場を画面幅・高さの20%以上移動させる。
- 三本の幅広い三次ベジェ光帯を異なる位相と曲率で循環させる。
- 3秒差の画面で光帯位置と曲率の変化を視認できる強度とする。
- 文字の背後では低コントラストを保ち、時刻の読みやすさを優先する。

## 5. 水面の光

- 基本周波数に対して比率と重みの異なる6方向の波を合成する。
- 一つは反対方向へ進め、単純な平行波にしない。
- 全幅の波輪郭は大きく曲げながら低不透明度に抑える。
- 干渉場から短い局所集光を生成し、格子状の線にしない。
- 白波は波頭へ付着して発生し、時間経過で広がり、ずれて、薄い残留泡へ遷移する。
- 静止画では横線よりも局所集光と白波を主役にし、動画では場全体の流れを感じられること。

## 6. 操作と配置

- 時計の時分は94sp、アラーム入力は82spを基準とする。
- タイマーは設定前48sp、動作中58sp、ストップウォッチは68spを基準とする。
- 外観操作は時計画面右上端の40dpアイコンだけとし、文字ラベルは表示しない。
- タイマーのテンキー、プリセット、開始操作は初期状態で隠す。
- タイマーの大きな時間領域をタップしたときだけ設定操作を展開する。
- アラームのテンキーと固定保存、ストップウォッチ操作は親指が届く画面下半分へ置く。

## 7. 省電力と受け入れ条件

- 背景と円周モーションは前景かつ対象画面の表示中だけ動かす。
- 省電力または「動きを減らす」時は背景、円周、数字モーフを停止する。
- API 26～36で同じ機能を保つ。
- 1.3倍フォントでも主要時間と固定操作が欠けない。
- 通常アラビア数字0～9の全テンプレートが正規化領域内にあり、実際の曲率を含む。
- Android 16でクラッシュ、ANR、入力不能、下端操作の欠けがない。
