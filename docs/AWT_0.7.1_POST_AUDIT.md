# AWT 0.7.1 改修後監査

- 対象: AWT 0.7.1 / versionCode 8
- 監査日: 2026-07-26
- 実動作環境: Android 16 / API 36、1080×2400

## 1. 改修内容

0.7.0の数字モーフは7本の線分で構成した表示だけだった。0.7.1では、通常の
アラビア数字0～9をAWT独自の連続モノライン字形として追加した。

- 各字形の折れ線を弧長に沿って56点へ再サンプリング
- 対応する制御点を補間し、数字を画像交換やクロスフェードではなく一つのパスとして変形
- Catmull-Rom相当の三次ベジェ補間で線を滑らかに描画
- 形状補間へ移動量、縮尺、グロー、残響を連動
- 「標準数字」を既定にし、「線分数字」も外観設定から選択可能
- 選択結果を端末内へ保存し、再起動後も保持
- 省電力または「動きを減らす」設定では中間アニメーションを停止

## 4. 設計上の注意

標準数字はOSフォントの輪郭データを変形しているのではなく、AWT用に設計した
モノライン字形である。このため端末フォント差に影響されず、全桁間で同じ制御点数を
保証できる。将来、別書体を追加する場合も同じ正規化・再サンプリング契約を守る。
