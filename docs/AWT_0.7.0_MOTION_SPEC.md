# AWT 0.7.0 モーション統合仕様

- 対象: AWT 0.7.0
- 作成日: 2026-07-26
- 前提: 他社アプリ固有の素材・コード・画面構成を使用しない独立実装

## 1. 目的

0.6.0で追加した装飾的なロールと常時回転する円周波を、時間・操作・背景が同じ運動則でつながる表現へ更新する。
背景は複数方式から選択可能にし、波打ち際シミュレーション最終盤で得た複合波、集光、白波残響の考え方を、時計向けの低輝度な「水面の光」として再構成する。

## 2. 背景モーション

外観設定に次の3方式を追加し、選択内容を端末内へ保存する。

- `Aurora`: 3つの光場が端で反転せず、閉じた軌道をゆっくり循環する。
- `Tidal Light`: 複数方向の波面、低輝度コースティクス、短い白波、残留光を重ねる。
- `Still`: グラデーションと静的な光だけを表示する。

背景描画は情報表示とは別の低頻度ループとし、`Tidal Light`は20fps、
`Aurora`は約15fpsを上限とする。数字モーフと時間リングはこの制限を受けない。

`Tidal Light`は海そのものを写実表示するモードではない。波打ち際シミュレーションの次の原理だけを、時計の可読性を妨げない抽象背景へ変換する。

- 周期と方向の異なる複数正弦波の合成
- 波面交差部に現れる細い集光線
- 波頂の短い高輝度区間
- 高輝度区間が拡散・減衰する残留光
- ページスワイプへ弱く追従する視差

## 3. 数字モーフ

- 数字をフォントの交換で表示せず、丸端を持つ7本のモノライン形状としてCanvas描画する。
- 変更前後で共通する線分は位置を維持する。
- 消える線分と現れる線分は、最短距離の組み合わせで移動・回転・伸縮させる。
- 対応する線分がない場合は、線分中央へ収束または中央から展開する。
- 変形中は低輝度グローと小さな慣性移動を同期させる。
- 複数桁の繰り上がりは右から左へ短い時間差で伝播させる。
- 「動きを減らす」時は変形を行わず、完成形を即時表示する。

## 4. 時間連動の円周波

- 時計: 秒＋小数秒を60秒で1周する位置へ変換する。
- タイマー: 開始から終了までの進捗を1周へ変換する。
- 設定中タイマー: 入力値の秒位置を円周上に示す。
- 秒境界または残り秒の変化時だけ、外側へ短い伝播波を発生させる。
- 常時6.4秒で回る意味のないループは廃止する。

## 5. スワイプの多層化

- HorizontalPagerの内容は指へ直接追従する。
- 各ページの前景は移動量の一部を相殺し、わずかな奥行きを作る。
- 背景の光場・波面は前景より小さな移動量で追従する。
- 指を戻した場合も離散的な切替を行わず、同じページオフセットから連続的に復帰する。
- 計測画面内のタイマー／ストップウォッチも横スワイプ可能にする。

## 6. 省電力・アクセシビリティ

- 背景と円周の連続描画はアプリ前面かつ対象画面表示中だけ行う。
- 省電力モードまたは「動きを減らす」では、背景を同じ構図の静止画へ落とす。
- `Tidal Light`の波面・屈折光はサンプル数を抑え、長い格子状の線を作らない。
- 数字モーフは即時表示へ切り替える。
- OLEDテーマは背景の黒を維持し、光の占有面積と不透明度を抑える。
- モーション方式を変えても情報の配置、コントラスト、タップ位置は変えない。

## 7. 受け入れ条件

- 背景方式を設定で切り替え、アプリ再起動後も保持できる。
- `Tidal Light`で複数方向の波面、集光線、白波から残留光への減衰が確認できる。
- 数字変更時に線分形状そのものが連続変形する。
- `09:59→10:00`相当の変更で右から左への時間差がある。
- 時計の円周波が秒位置と一致する。
- タイマーの円周波が開始時0、終了時1周へ進む。
- 左右スワイプ中に背景と前景の移動量が異なる。
- 省電力または「動きを減らす」で連続アニメーションが停止する。
- API 26～36でコンパイルでき、API 36でクラッシュ、ANR、主要画面の欠けがない。
