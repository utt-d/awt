# AWT 0.6.0 時間表示・モーション仕様

- 対象: AWT 0.6.0
- 作成日: 2026-07-23
- 前提: 他社アプリ固有の素材・コード・画面を使用しない独立実装

## 1. 目的

時間を画面の主役として一段大きくし、テンキーと主要操作を親指側へ寄せる。
数字の変化は単純なフェードではなく、時間の進行方向、弾性、光の残響が一体になったAWT独自の表現へ更新する。

## 2. 縦配置

### アラーム編集

- 設定時刻を52spから64spへ拡大する。
- 見出しと時刻の間に10dpの余白を加える。
- 入力案内とテンキーの間を16dp広げ、テンキーを下げる。
- キャンセル／保存は既存どおり下端固定とする。
- 1.3倍フォントで横幅に収まり、下部操作はスクロール位置に依存しないこと。

### タイマー

- 6桁設定時刻を31spから34spへ拡大する。
- 残り時間を38spから42spへ拡大する。
- 上端余白と円形表示後の余白を合計20dp増やし、テンキーと開始操作を下げる。
- 動作中は円形表示と延長／キャンセル操作の間を88dpとし、操作を画面中央より下へ寄せる。
- モード切替と主要ナビゲーションは下端固定のまま維持する。

## 3. 桁モーション

### 3.1 意味に合う方向

- 時計、ストップウォッチ: 数字を下から上へ送り、時間の増加を表す。
- タイマー: 数字を上から下へ送り、残時間の減少を表す。
- 直接入力: 入力数字の大小に応じて方向を選ぶ。
- `9→0`などの繰り上がりは時計では増加方向として統一する。

### 3.2 弾性ロール

- 新しい桁は55%の大きさと約75%桁高の位置差から進入する。
- Springで100%へ収束させ、短いオーバーシュートを含める。
- 古い桁は進行方向と反対へ抜け、134%まで拡大しながら消える。
- フェードは移動より先に立ち上げ、数字の判読不能時間を短くする。
- 各桁の文字には低不透明度のテーマ色グローを付ける。

### 3.3 桁バースト

- 変更された桁の背後に、560msで消える二重リングを描く。
- 4個の微小な光点を回転・拡散させる。
- リングと粒子は字形の外縁から開始し、`0`などの内側を装飾で塞がない。
- バーストは変更桁だけに生成し、固定記号には生成しない。
- 「動きを減らす」時は生成しない。

## 4. 外周コメット波

- 時計・タイマーの二重軌道と時計回りの進行は維持する。
- 離れた弧の列を廃止し、連続したSweep Gradientシェーダーで光跡を描く。
- 光跡は広い低不透明度グローと細い高輝度コアの2層で描く。
- 尾に向かって不透明度を段階的かつ連続的に減衰させる。
- 波頭は外側グロー、中心光、短い先行粒子で構成する。
- Primary／Secondaryの二つの波を180度ずらし、内外の軌道に置く。
- 周期は6.4秒を維持し、急加速・停止のない線形進行とする。

## 5. 省電力・アクセシビリティ

- 前面かつ対象画面選択中のみ外周アニメーションを生成する。
- 省電力または「動きを減らす」時は、外周波と桁バーストを静止／停止する。
- 同条件では桁ロールを即時表示へ切り替える。
- 時計・タイマー1Hz、ストップウォッチ4Hzの省電力更新頻度を維持する。

## 6. 受け入れ条件

- アラーム時刻とタイマー時刻が0.5.0より大きく見える。
- テンキー開始位置が0.5.0より下にある。
- 下部保存、開始、計測モード切替が欠けない。
- 増加表示とカウントダウンで桁の進行方向が逆になる。
- 変更桁だけに弾性ロール、グロー、光バーストが見える。
- 外周の尾が離散的な点線ではなく、滑らかなコメット状に見える。
- 1.3倍フォントでも時刻が横幅に収まる。
- API 36でクラッシュ、ANR、レイアウト切れがない。
