# AWT 0.7.0 改修後監査

- 対象: AWT 0.7.0 / versionCode 7
- 比較対象: AWT 0.6.0
- 監査日: 2026-07-26
- 実動作環境: Android 16 / API 36、1080×2400

## 1. 実装結果

時間、操作、背景を別々の装飾として動かす構成を改め、同じ進行値へ結び付けた。
他社アプリの素材、コード、字形、画面構成は使用していない。

- 7本のモノライン線分を補間する連続的な数字モーフ
- 右から左へ短い時間差を付けた複数桁の変形
- 時計の秒位置へ同期する円周波
- タイマーの開始から終了までの進捗へ同期する円周波
- 前景、ページ、背景の移動量を分けたスワイプ視差
- 計測画面内のタイマー／ストップウォッチ横スワイプ
- Aurora／水面の光／静止の3背景と選択内容の端末内保存
- 波打ち際シミュレーションの複合波、集光、白波残響を抽象化した水面背景

## 2. 水面の光

写実的な海を表示せず、時計表示を妨げない低輝度の背景へ再構成した。

- 周期と方向の異なる8本の波面
- 全画面格子を作らない6本の局所的な屈折光
- 高輝度から残留光へ減衰する4か所の短い波頂
- ページスワイプへ弱く追従する位相差
- 18秒で継ぎ目なく循環
- 前景表示中だけ最大20fpsで更新

初期候補では長い屈折線が格子に見えたため、局所的な短い線へ変更した。
描画サンプル数と更新頻度も減らし、数字と時間リングの滑らかさを維持したまま
背景だけを低頻度化した。

## 3. 数字と円周

- 数字はフォント交換や新旧文字の重ね合わせではなく、線分の位置、角度、長さを補間する。
- 共通する線分は固定し、消える線分と現れる線分だけを最短の組み合わせで変形する。
- 時計とストップウォッチは増加方向、タイマーは減少方向の微小な慣性を持つ。
- タイマー10秒の連続録画で`09→08→07…`の変形と残量円周を確認した。
- 「動きを減らす」では線分補間を行わず完成形を即時表示する。
- 各数字はTalkBack上で実際の桁値として認識される。

## 4. 設定と省電力

- 背景方式は外観設定から切り替えられる。
- 「静止」を選択してアプリを強制終了・再起動し、選択が保持されることを確認した。
- 検証後は「水面の光」へ戻し、保存値が`TidalLight`であることを確認した。
- 「動きを減らす」ONでは、3秒差の背景領域の画像ハッシュが一致した。
- 省電力モードと「動きを減らす」は背景、円周の伝播波、数字モーフを止める。
- Auroraは約15fps、水面の光は20fpsを上限とする。

## 5. 描画計測

API 36のヘッドレス・ソフトウェア描画エミュレータで同一条件を比較した。
これは実機GPUの絶対性能を示す値ではなく、改修前後の相対比較だけに使用する。

| 水面背景 | 50th percentile | 90th percentile |
|---|---:|---:|
| 最適化前 | 109ms | 125ms |
| 最適化後 | 44ms | 48ms |

波面数、サンプル数、屈折線長、背景更新頻度の削減により中央値を約60%短縮した。
