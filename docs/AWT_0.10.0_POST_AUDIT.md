# AWT 0.10.0 改修後監査

- 対象: AWT 0.10.0 / versionCode 11
- 監査日: 2026-07-26
- 対象OS: Android 8.0（API 26）以上

## 1. 結果

0.9.0で残っていた標準数字の字形、色選択、水面の白波と泡、時計周囲の円形表示、
タイマーとストップウォッチの操作体系を改修した。

## 2. 標準数字モーフ

- 手描きの一筆線数字を、Androidの標準`sans-serif`フォントから取得した塗り輪郭へ置き換えた。
- 0～9で共通の字面範囲を使い、外周と内側カウンターを各52点へ再標本化する。
- 遷移元と遷移先の開始位置・向きを最小距離で合わせ、輪郭全体を連続補間する。
- `4`は端末の標準フォントと同じ開口、横棒、縦幹を持ち、独自曲線による潰れを解消した。
- 0、6、8、9の内側空間はEven-Odd塗りで保持する。
- 従来の線分数字は選択肢として残す。

## 3. カラーパレット

- 背景色と文字色を独立して選択できる。
- 上段の2次元パレットで彩度と明度、下段の色相帯で色相を直接ドラッグする。
- 選択色はプレビューへ即時反映し、SharedPreferencesへ保存する。
- 「既定」でテーマ連動色へ戻せる。

## 4. 水面の光

- 6方向の複合波、解析的な勾配・曲率、法線、集光をOpenGL ES 2.0で描画する。
- 画面を横切る人工的な直線白水帯を使用しない。
- 活動白波は、その瞬間の合成波高、局所曲率、傾斜へ付着する。
- 同じ泡沫キャリアを現在、0.42秒前、0.96秒前で参照し、高密度白波から移行中の白水、
  低密度の残留泡へ連続的に変化させる。
- 泡斑は低コストのセル状マスクで途切れを作り、別CPU粒子系や追加レンダーパスを使わない。
- 白色混合量、鏡面反射、コースティクスを抑え、時刻文字とのコントラストを確保した。
- 基準描画幅を288pxから320px、更新を20fpsから約24fpsへ変更し、輪郭のジャギーを抑えた。
- シェーダーは`glslangValidator`で構文検証済みである。

## 5. 時計と計測操作

- 時計周囲の円形アニメーションへ表示／非表示スイッチを追加し、設定を保存する。
- タイマーの開始操作は、設定パネルを閉じていても時間円内へ常時表示する。
- 実行中は同じ位置を一時停止へ切り替え、停止を隣接表示する。
- 一時停止中は残り時間と進捗リングを固定し、同じ位置から再開できる。
- 一時停止時間はプロセス再生成後も保持し、再開時に正確なシステムアラームを再登録する。
- ストップウォッチも、開始／一時停止とリセット／ラップを同じ円形オーバーレイへ統一する。

## 7. 検証上の注記

一度Windows側のQEMUが終了したため操作確認を中断したが、ユーザーがAndroid 16
エミュレータを再起動した後、Computer Useで同一セッションの主要操作を通して確認した。
標準数字の`4`、背景色パレット、時計円形表示のオン／オフ、水面背景、タイマーと
ストップウォッチの各状態遷移を実画面で確認し、最終APKのlogcatにもAWTの
Fatal Exception／ANR、シェーダーコンパイル失敗はなかった。

水面背景は、初回候補で白い泡斑が大きく文字へ重なったため公開を止め、波頂リッジへ
泡沫マスクを限定し、泡粒を細分化、鏡面反射・集光・白色混合を再調整した。
再ビルド後は、複数フレームで泡と白波の移動、文字コントラスト、ジャギーの目立ち方を
再確認した。エミュレータ上では視認性と連続性に問題はない。

60／90／120Hzの実機GPUにおける消費電力とフレーム時間は、端末差を含むため今後も
実機評価項目とする。
