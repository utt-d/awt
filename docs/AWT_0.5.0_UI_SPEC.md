# AWT 0.5.0 UI改修仕様

- 対象: AWT 0.5.0
- 作成日: 2026-07-23

## 1. 目的

0.4.0で残った「上端への偏り」「無効値を入力してから気付く」「時間表示の視覚的な物足りなさ」を改善する。
全画面の没入感を維持しながら、カメラ穴との衝突を避け、主要操作を片手で届く位置へ移す。

## 2. 安全領域と縦配置

- 通常画面とアラーム編集は、Androidの`safeDrawing`上端を本文の開始位置とする。
- 状態バーは引き続き非表示にするが、カットアウト領域を本文配置には使わない。
- アラーム編集の上端には非操作の見出しだけを置く。
- キャンセル／保存は52dp高のボタンとして下端に固定し、システムナビゲーション領域の上に置く。
- タイマーの円形表示は0.4.0より16dp下げる。
- ストップウォッチの主表示は0.4.0より154dp下げ、開始／停止ボタンを画面中央付近へ置く。
- 主ナビゲーションと計測モード切替は既存どおり画面下部に固定する。

## 3. 先回りする入力制約

### アラーム `HHMM`

| 入力位置 | 有効数字 |
|---|---|
| 時・十の位 | 0〜2 |
| 時・一の位（先頭0/1） | 0〜9 |
| 時・一の位（先頭2） | 0〜3 |
| 分・十の位 | 0〜5 |
| 分・一の位 | 0〜9 |

### タイマー `HHMMSS`

| 入力位置 | 有効数字 |
|---|---|
| 時・十／一の位 | 0〜9 |
| 分・十の位 | 0〜5 |
| 分・一の位 | 0〜9 |
| 秒・十の位 | 0〜5 |
| 秒・一の位 | 0〜9 |

- 無効キーはカード背景と文字の不透明度を下げてグレー表示する。
- 無効キーにはクリック処理を登録しない。
- 4桁／6桁入力済みの状態で次の数字を押す場合は、新規入力の先頭として判定する。
- パーサーによる最終検証も残し、UI制約とデータ制約を二重化する。

## 4. 時間表現

### 数字

- 変化する桁は進行方向へ上下移動する。
- 新しい桁は72〜74%から100%へ拡大しながらフェードインする。
- 古い桁は116〜118%へ拡大しながらフェードアウトする。
- 入力中の桁にも短い拡縮を加え、押下結果を視覚的に返す。

### 時計回りの波

- 時間表示を囲う円周上に、テーマのPrimary／Secondary色の二重波を描く。
- 各波は先頭光点と10個の短い残響弧で構成する。
- 二つの波は180度ずらし、内外二重の軌道に置く。
- 1周6.4秒で時計回りに進む。
- 停止時も薄い軌道と静止した波頭を残し、外観の連続性を保つ。

## 5. 電池・アクセシビリティ

- 時計の波は時計画面が選択され、アプリが前面、省電力OFF、「動きを減らす」OFFの場合だけ動く。
- タイマーの波も計測／タイマー画面が選択された場合だけ同条件で動く。
- それ以外では無限アニメーションを生成せず、静止描画に切り替える。
- 省電力または「動きを減らす」時は、時計とタイマーの表示更新を1Hzに抑える。
- ストップウォッチは省電力または「動きを減らす」時に4Hzへ抑え、経過計算は単調時計で正確に保つ。
- 「動きを減らす」では桁の拡縮を含む遷移も行わない。

## 6. 受け入れ条件

- 上部カットアウトと見出し、時刻表示、ボタンが重ならない。
- アラーム編集のキャンセル／保存がスクロール位置にかかわらず下部に見える。
- `24:xx`、`xx:6x`につながる数字を入力できない。
- タイマーの分・秒の十の位で6〜9を入力できない。
- 無効数字が有効数字と見分けられる。
- 数字変更時に上下移動、フェード、拡縮が見える。
- 時計／タイマーの外周波が時計回りに進む。
- 省電力または「動きを減らす」で外周波が静止する。
