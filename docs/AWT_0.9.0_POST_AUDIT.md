# AWT 0.9.0 改修後監査

- 対象: AWT 0.9.0 / versionCode 10
- 監査日: 2026-07-26
- 実動作環境: Android 16 / API 36、1080×2400、420dpi

## 1. 結果

0.8.0で残っていた数字`4`の判読性、背景モーションの表現方式、操作位置、時間表示の大きさ、
Auroraの境界とループ、色選択の自由度を修正した。

## 2. 数字モーフ

- 標準数字の`4`を、閉じたカウンター、幅のある横線、下まで伸びる幹で再構成した。
- 直線の組み合わせではなく三次ベジェ曲線を用い、他の標準数字と同じ56点へ再サンプリングする。
- `0～9`間のモーフは同一の点数と並びを維持する。
- 専用テストで、カウンター、横線、幹、曲率を検証する。

## 3. 水面の光

- Compose Canvasによる近似背景を廃止し、GLSurfaceViewでOpenGL ES 2.0を直接実行する。
- 6方向の複合波、領域の歪み、解析的な勾配と曲率、法線、集光、岸側の白波、残留泡を
  `tidal_surface.frag`で描画する。
- 取得できなかった参照実装のソースを複製したものではなく、確認できた運動則から独立再構成した
  GLSLシェーダーである。
- WebViewのWebGL可否に依存しない。

## 4. Aurora

- 線状の帯を廃止し、4個の大きくぼけた光場だけで構成する。
- 全ての光場を18秒周期の整数調波で移動させ、周期の先頭と末尾で位置と色が一致する。
- 端で方向反転する往復運動を使わない。
- 静的なアラーム一覧を4秒間隔で取得し、背景画像が変化することを確認した。

## 5. 描画と省電力

- OpenGL描画バッファは幅288pxを基準とし、画面比率を維持する。
- 更新は20fpsを上限とし、対象画面が前景にある間だけ要求する。
- 省電力モードまたは「動きを減らす」が有効な場合は静止表示へ切り替える。
- API 36エミュレータではシェーダーのコンパイル失敗、アプリのクラッシュ、ANRはなかった。
- エミュレータのソフトウェアEGLとSurfaceViewを含むフレーム統計は実機GPU性能を代表しないため、
  性能値としては採用していない。60/90/120Hz実機での計測は残課題とする。

## 6. 配置と文字サイズ

- 外観アイコンを時計画面の左下端へ移動した。
- タイマーの設定値は画面中央の360dp円内へ配置した。
- タイマーは設定中64sp、動作中は1時間未満84sp、1時間以上64spを基準とする。
- ストップウォッチの主表示は104sp、百分の一秒は36spとする。
- ストップウォッチの操作群を330dp下げ、表示との間隔を64dp確保した。
- フォント倍率1.3倍で、タイマー6桁、ストップウォッチ、各操作が欠けないことを確認した。

## 7. フルカラー設定

- 背景色と文字色を独立したHSVスライダーで選択できる。
- 色相、鮮やかさ、明るさを全範囲で変更できる。
- ピッカーは通常折りたたみ、行を押したときだけ展開する。
- 背景色と文字色をそれぞれ変更し、アプリ再起動後もSharedPreferencesへ保持されることを確認した。
- 「既定」でテーマ連動色へ戻せる。

## 9. 残課題

- 元の波打ち際シミュレーションの完全なソースが取得できないため、ピクセル単位の同一性は保証しない。
- 60/90/120Hzの実機GPUで、消費電力とフレーム時間を計測する。
- 実利用者による数字モーフ、背景の速度、コントラストの好みを評価する。
